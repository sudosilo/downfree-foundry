Mount the phone sideways in the same spot every drive, then tap Start camera.

Each part saves two files with matching names: the video, and a timing file with GPS, speed and heading tied to the video's clock. Keep both together.

1. Clips

Pick two or more clips of the same stretch of road. The clip marked Base supplies the road.

2. Line up

Each drive started recording at a different spot on the road. Line up makes every clip start at the same spot. Tap Auto line up first.

The picture flips between the Base clip and one other clip. When they are lined up, the road, signs and hills stay still and only the cars change. If things jump, nudge that clip's Start slider.
